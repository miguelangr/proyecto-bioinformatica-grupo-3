# Proyecto Bioinformática - Grupo 3

## Descripción

Este es un proyecto de ejemplo desarrollado por el **Grupo 3** para demostrar el uso de Git y GitHub en colaboración para proyectos de bioinformática. 

El objetivo principal es aprender a:
- Crear y gestionar repositorios
- Realizar commits de forma organizada  
- Colaborar mediante ramas y pull requests
- Documentar proyectos científicos

## Equipo

Los miembros del Grupo 3 y sus roles están detallados en [`docs/equipo.md`](docs/equipo.md).

## Estructura del Proyecto

```
proyecto-bioinformatica-grupo-3/
├── data/          # Datos de ejemplo
├── docs/          # Documentación del equipo
├── scripts/       # Scripts de análisis (futuros)
└── results/       # Resultados (futuros)
```
